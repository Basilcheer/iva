# Шаг «период»

Во входе: `period` (weekly, monthly, yearly), `id` и `children` — выжимки частей периода: `id`, `summary` (одна строка) и `missing` — данных за часть нет.

Сверни выжимки частей в выжимку периода. Не добавляй ничего, чего нет во входе.

Ответ — один JSON-объект в тексте, без пояснений:
- `gist` — одна фраза о периоде; `topics` — 1–5 коротких тем;
- `points` — главные пункты: `text` и `src` — список `id` частей из входа.

Перед ответом проверь, сделано или не сделано:
- каждый пункт опирается на часть из входа;
- ничего не добавлено сверх входа.

Пример:
{"gist":"Неделя запуска Авроры","topics":["проекты"],"points":[{"text":"Запущен проект Аврора","src":["2026-09-22"]}]}
