# Единственная железная гарантия — данные пользователя не теряются

Из всех возможных гарантий (атомарный апдейт, forward-совместимость конфигов,
недействие агента вовне без санкции владельца) статус нерушимой получает одна:
память, vault, история и конфиги пользователя не теряются никогда — ни при апдейте,
ни при откате, ни при краше агента. Нарушение этой гарантии блокирует релиз без
обсуждения. Остальные гарантии — цель и best effort: объявить их железными сегодня
значило бы выписать чек, который кодовая база пока не обналичит (13 инцидентов
`iva update` за 7 недель; sanitizer/outbound-контур не достроен). По мере готовности
механизмов отдельные гарантии могут повышаться до железных новым ADR.
