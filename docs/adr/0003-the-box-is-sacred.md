# Коробка священна: install и update важнее фич

При конфликте скорости релизов и надёжности пути «поставить/обновить» побеждает
надёжность: открытый баг в install или update блокирует фичевую работу и чинится
первым. Каденция релизов (сложившаяся — раз в ~2 дня) при этом имеет право падать.
Обоснование: обещание «работает из коробки» (ADR-0001) проверяется ровно в двух
местах — install.sh и `iva update`; сломанная коробка обесценивает любую фичу за ней.
Отвергнутые альтернативы: «early adopters потерпят» (противоречит ADR-0001) и
каналы stable/edge (двойной трек поддержки и бэкпорты непосильны для одного
мейнтейнера на текущем масштабе).
