# Self-hosters — полноправные пользователи, а не зрители

Iva публична не как витрина: за первые 7 недель — 137 звёзд, 27 форков, ~640 уникальных
клонов за две недели, большинство issues и ~20 PR приходят от чужих инсталляций.
Решено: чужой self-hoster — полноправный клиент проекта. Планка — «работает из коробки
как продукт»: каждое решение проверяется вопросом «а если это поставит чужой человек,
без автора рядом?». Альтернатива — считать реальным пользователем только владельца, а
репозиторий портфолио — отвергнута: популяция инсталляций уже существует и растёт, и
резать углы (onboarding, чужие конфиги, миграции) значило бы врать этим людям.
